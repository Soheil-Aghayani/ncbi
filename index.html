Literature & Taxonomy

Over 36 million biomedical citations and the tree of life.

Literature
Database Distinctions
PubMed (Index Only) The world's largest biomedical citation index — 36M+ abstracts. Free to search, links to publisher sites. No guarantee of free full text.
PMC (Full Text Archive) PubMed Central provides completely free, open-access full text of millions of journal articles. Mandated by NIH for federally funded research.
Taxonomy System
Tree of Life Curated classification covering 8 ranks: Domain → Kingdom → Phylum → Class → Order → Family → Genus → Species. Linked to all sequence records.
Search Operators
Boolean operators and field tags power precision searches.
[MeSH] [Author] [TIAB] AND / OR / NOT

ClinVar & Genetics

Connecting human genomic variations to health and disease.

Clinical
Variant Classifications
Pathogenic / Likely Pathogenic Strong evidence the variant causes disease. Used in clinical diagnostics and genetic counseling reports.
VUS (Variant of Uncertain Significance) Insufficient evidence to classify. Common bottleneck in clinical genomics — reclassified as data accumulates.
Benign / Likely Benign Evidence supports no disease association. Often common population variants with high allele frequency.
Key Relationships
ClinVar links each variant to:
Gene Condition (OMIM) dbSNP rsID Clinical assertion

Genomes & GenBank

Comprehensive DNA/RNA sequence repositories.

Genomics
Core Databases
GenBank (Archival) Open-access — anyone can submit sequences. Over 500 billion nucleotide bases. Accepts raw, unverified submissions.
RefSeq (Curated) NCBI-curated, non-redundant reference sequences. Each entry manually reviewed. Gold standard for genome annotation. Prefix: NM_ (mRNA), NP_ (protein), NC_ (chromosome).
FASTA Format
Standard sequence format. Header line starts with > followed by accession and description. Sequence follows on next lines.
>NC_000001.11 ATCGGCTAA...
INSDC Partnership
GenBank synchronizes daily with EMBL-EBI (Europe) and DDBJ (Japan) — forming the International Nucleotide Sequence Database Collaboration.

Protein Structures

Amino acid sequences, domains, and 3D modeling.

Structure
Structural Databases
PDB Integration Links directly to the Protein Data Bank for experimentally-determined 3D structures via X-ray crystallography, cryo-EM, or NMR.
CDD (Conserved Domain DB) Identifies functional domains and conserved motifs within a query protein sequence. Uses position-specific scoring matrices (PSSMs).
Scoring: BLOSUM62
Standard substitution matrix for protein alignments. Derived from blocks of ungapped alignments of related proteins with ~62% identity. Positive scores = favorable substitutions; negative = costly.
Trp→Trp: +11 Trp→Gly: -3
Protein DB Types
nr (non-redundant) UniProt/Swiss-Prot PDB sequences RefSeq proteins

Sequence Read Archive

The largest public repository of raw NGS sequencing data.

Big Data
Next-Gen Sequencing
Raw Reads (FASTQ format) Stores petabytes of unaligned reads from Illumina, PacBio, Oxford Nanopore platforms. Each read has 4 lines: ID, sequence, separator, quality scores.
FASTQ Quality Scores Phred quality scores (Q) encoded as ASCII characters. Q20 = 99% accuracy. Q30 = 99.9% accuracy. Minimum threshold for most bioinformatics pipelines.
Access Tools
fasterq-dump prefetch SRA Toolkit AWS Open Data

BLAST Tool

Basic Local Alignment Search Tool logic & metrics.

Alignment
Scoring & Metrics
E-Value (Expect Value) Expected number of hits of similar quality by chance alone. E < 0.001 = significant. E = 3e-14 = near-perfect match. Lower is better.
Bit Score Normalized alignment score — higher is better. Comparable across databases of different sizes. Derived from raw score using Karlin-Altschul statistics.
Algorithm Variants
blastn (DNA→DNA) blastp (prot→prot) blastx (DNA→prot) tblastn (prot→DNA) megablast
How BLAST Works
1. Seed → Extend → Score Splits query into short "words" (k-mers). Finds exact matches in DB. Extends alignment in both directions while score stays above threshold. Applies Smith-Waterman locally.

The Genetic Disease Workflow

How researchers traverse the NCBI network to solve a clinical case. Hover each step for details.

Step 01
PubMed
Query literature for symptoms.
PubMed Search Use MeSH terms + symptom keywords. Filter by review articles to get an overview of known genetic causes for the phenotype.
Step 02
ClinVar
Identify pathogenic variants.
ClinVar Lookup Search the candidate gene. Filter by "Pathogenic" or "Likely Pathogenic." Cross-reference with patient's variant from sequencing data.
Step 03
GenBank
Pull the reference DNA.
Fetch RefSeq Download the canonical mRNA transcript (NM_*) or chromosome region (NC_*) as FASTA for local comparison and annotation.
Step 04
Proteins
Analyze broken 3D structures.
Structure Analysis Use PDB viewer to inspect wild-type vs mutant protein folding. CDD reveals if variant disrupts a conserved functional domain.
Step 05
BLAST
Align sequence to find origins.
blastp / blastn Run the mutant protein against nr database. Low E-value hits confirm the affected domain is conserved across species — supporting pathogenicity.
